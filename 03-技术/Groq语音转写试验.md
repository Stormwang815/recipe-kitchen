# Groq 语音转写试验

日期：2026-11-20。状态：试验入口和本地模拟测试完成；没有 Groq API Key，尚未完成真实转写。

## 本次实现

导入页 → Groq 语音转写（试验） → 用户填写自己的 Groq Key → 选择音频或 MP4 → 确认上传 → 显示文字及时间段 → 编辑 → 带入菜谱整理。

默认模型 whisper-large-v3-turbo，可切换 whisper-large-v3；默认指定中文，可关闭以自动识别。文件上限25MiB，真实服务大小判定仍以Groq为准，建议先用远小于上限的10–30秒口播。

语音识别和文字整理配置分开，不把Groq音频API误填到Chat Completions地址。完成转写后不会自动调用文字模型，用户明确选择才生成菜谱草稿。完整视频理解、OCR和自动截图仍未实现。

## 传输与密钥

试验采用 wx.uploadFile 从小程序直接上传到固定的 https://api.groq.com/openai/v1/audio/transcriptions，不经过kitchen函数，不受云函数3/60秒限制。使用Bearer Key、multipart file、verbose_json、可选language和固定temperature。

Groq密钥默认只留在本次运行内存，明确选择才写入本机独立存储；不写入厨房、云数据库或菜谱备份。上传前说明文件发送给Groq及账号额度边界。用户可以取消上传；发出的服务端处理是否立刻终止不能保证。

文件选择支持微信文件入口及相册视频。仅支持文档列出的格式，不把MOV重命名后当成MP4。临时文件无扩展名时按原文件名复制到本机临时用途路径，结束后清理；进程异常退出可能留下文件，后续需补启动清理。
